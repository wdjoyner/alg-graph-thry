# Complement–regularity

Project folder for a corrected edition of David Joyner's *Which S_m have a complement in S_n?* (1997; revised 2007).

Draft 3 has been prepared as LaTeX and PDF with a revision log and a preliminary outline of connections to arrangement graphs, coset graphs, Cayley graphs, and Johnson graphs.

**Status:** The manuscript files are prepared but have not yet been uploaded to this folder. External classification citations and historical GAP calculations still require independent verification.
